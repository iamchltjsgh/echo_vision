# 이웃 프라이버시 마스킹 — ESP32 계약(Contract)

이 문서는 서버(`server/app.py`)와 ESP32 펌웨어 사이의 데이터 계약을 정의한다.
좌표를 사용자가 지정하고 서버에 저장하는 것까지는 이 저장소(Flutter 앱 + Flask
서버)의 책임이고, **촬영 시점에 실제로 픽셀을 블러/모자이크 처리하는 로직은
ESP32 펌웨어(이 저장소 밖)의 책임**이다.

## 설계 원칙

- 카메라는 문에 고정 부착되어 화각이 거의 안 바뀐다. 그래서 촬영마다 AI로 이웃집
  문을 다시 찾는 대신, **설치 시 한 번 지정한 좌표를 계속 재사용**하는 방식으로
  설계했다.
- 마스킹은 **법적 의무가 아니라 권장 사항**이다. 좌표가 없으면(설정 안 함) 그냥
  원본 그대로 처리하면 된다 — 강제하지 않는다.

## 반드시 지켜야 할 것 (가장 중요)

**마스킹은 촬영 직후, SD카드 저장 및 서버 전송(HTTP POST) 이전 단계에서
적용되어야 한다. 마스킹 안 된 원본이 SD카드에 저장되거나 서버로 전송되면
안 된다.** 서버나 앱은 이미 마스킹된 이미지만 받아서 다루는 것을 전제로
설계되어 있고, 그 전제가 깨지면(원본이 어딘가에 남으면) 이 기능의 존재 의미가
없어진다.

## 엔드포인트

### `GET /device/mask-regions`

ESP32가 부팅 시, 그리고 주기적으로(예: 몇 분~몇십 분 간격 폴링, 정확한 주기는
펌웨어 쪽 배터리/네트워크 예산에 맞춰 정하면 된다) 호출해서 최신 마스킹 좌표를
받아간다.

응답:
```json
{
  "regions": [
    {"x": 0.62, "y": 0.10, "width": 0.25, "height": 0.55},
    {"x": 0.05, "y": 0.15, "width": 0.20, "height": 0.40}
  ]
}
```

- `regions`가 빈 배열이면 마스킹 없이 원본 그대로 처리한다.
- 최대 4개까지 온다(서버가 저장 시점에 이미 제한을 걸어둔다 — ESP32 쪽에서 개수
  제한을 다시 검증할 필요는 없지만, 혹시 몰라 5개 이상이 오더라도 방어적으로
  전부 적용하거나 앞 4개만 적용하는 등 크래시 없이 처리하는 걸 권장한다).

### `POST /device/mask-regions`

앱의 설치 모드 화면이 사용자가 지정한 좌표를 저장할 때 호출한다. **ESP32가 호출할
일은 없다** — ESP32는 GET만 사용한다.

### `GET /device/mask-regions/status`

앱 설정 화면이 "현재 마스킹 설정 상태"를 보여줄 때 쓴다. **ESP32가 호출할 일은
없다.**

## 좌표계

- 좌표는 이미지 **전체**를 가로/세로 각각 0.0~1.0으로 정규화한 비율 값이다.
  `x`, `y`는 좌상단 기준 시작점, `width`, `height`는 그로부터의 비율 크기다.
- 실제 촬영 해상도가 바뀌어도(예: 나중에 센서를 더 높은 해상도로 교체해도)
  좌표 자체는 그대로 유효해야 한다 — 그래서 픽셀이 아니라 비율로 저장한다.
- ESP32는 이 비율 값을 **실제 촬영 해상도(가로 W px, 세로 H px)에 맞춰 픽셀
  좌표로 변환**해서 적용해야 한다:
  ```
  pixel_x      = round(x * W)
  pixel_y      = round(y * H)
  pixel_width  = round(width * W)
  pixel_height = round(height * H)
  ```
- 앱이 보내기 전에 이미 `0.0 <= x, y <= 1.0`, `0.0 < width, height <= 1.0`,
  `x + width <= 1.0`, `y + height <= 1.0`을 서버가 검증해서 거부하므로, ESP32는
  좌표가 항상 이미지 범위 안이라고 신뢰해도 된다.

## 처리 순서 요약

```
촬영 → (regions가 있으면) 각 영역을 블러/모자이크 처리
     → SD카드 저장
     → 서버로 업로드(HTTP POST)
```

마스킹 단계를 건너뛰고 저장/전송하면 안 된다. regions가 비어 있으면 그냥
원본을 그대로 저장/전송한다.
